# LAST GRIP example

Use the sibling Narae Unity app or `Tools/unity-cli.ps1 -Action Export` to generate `Build/LastGrip`.

Install dependencies with `python -m pip install -r Tools/IndependentExporter/requirements.txt`.

This example contains authored source and native serialization schema metadata. It does not include the official SDK DLL or Unity/game runtime. Independent Export works without them; editing in Unity requires the official Workshop SDK.

See the repository README and Docs/native-validation.json for validation scope. Human playthrough and multiplayer remain unverified.
